# Getting Started

Follow these guides to get PosternProxy running. Choose an install path:

- [Installation]({{< relref "/getting-started/installation" >}}) — native systemd
  on Debian/Ubuntu amd64 and arm64.
- [Docker]({{< relref "/getting-started/docker" >}}) — amd64/arm64 container images
  for the controller and agent.
- [Windows services]({{< relref "/getting-started/windows" >}}) — native amd64
  service installation.

Then work through the [Quick Start]({{< relref "/getting-started/quick-start" >}}).
